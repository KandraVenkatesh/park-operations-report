# Park Operations Daily Report Tool

A small reporting tool for a fictional amusement park, built to practise Python and SQL.
**All data is simulated. Results are illustrative, not real findings.**
The problem
Managers at a park often compile weekly visitor, sales and wait-time reports by hand in Excel.
This is slow and easy to get wrong. This tool replaces that with one command.
How it works

1. `generate_data.py` creates about 22 months of daily data using simple rules (weekends, holidays and rain change visitor numbers; wait time rises when there are more visitors per staff member) and stores it in a SQLite database.
2. `analysis.py` uses SQL queries to compare weekdays and weekends, monthly totals, busiest days, and how often long waits happen.
3. `report.py` uses pandas to build a weekly summary and saves it as an Excel file with a Weekly sheet and a Summary sheet.
4. `check.py` verifies a weekly total with a separate SQL query.

How to run
```
python generate_data.py
python report.py
python check.py
```
Requires Python, pandas and openpyxl. Close `weekly_report.xlsx` in Excel before re-running.

How I checked it
- I compared a weekly total in the report (44,184 visitors for the week ending 2025-05-04) with an independent SQL query for the same dates. They matched.
- I found that the first and last weeks have fewer than 7 days, which made "change vs last week" misleading. I added a visitors-per-day column and a "Complete week?" flag, and excluded incomplete weeks from the summary.

Assumptions and limits
- Data is generated by my own rules, so patterns such as "rain lowers visitors" are built in, not discovered.
- The holiday list is simplified and incomplete.
- It is not real-time and is not based on any real company's operations.

What I would ask frontline staff
- Which numbers do you actually use from the weekly report?
- Which step takes the longest when you prepare it?
- What mistakes happen most often?

What I would do next

- Measure report preparation time before and after, and whether managers keep using it.
